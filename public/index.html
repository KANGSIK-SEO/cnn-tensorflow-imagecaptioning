      이 결과는 참고용이며 감정서가 아닙니다. 그림을 실제로 사고팔 때는 전문 감정기관에 맡기세요.

      어떻게 동작하나요

      • CNN: MobileNetV2(ImageNet 사전학습)를 전이학습해 작가 15명의 화풍을 구분하고, 그림의 특징 벡터로 미술관 소장품 약 3,500점과 비교합니다. 미술관에 있는 원작과 똑같은 그림이 "진품"으로 팔린다면, 그 원작 사진을 복제했을 가능성이 큽니다.
      • 이미지 캡셔닝: CNN 특징을 GRU 디코더에 넣어 시대·문화권·기법·주제를 한 단어씩 만들어 냅니다.
      • 기기 안 추론: TensorFlow.js로 이 폰 안에서 돌아갑니다. API 키·서버가 필요 없고, 처음 열 때 앱과 모델(약 12MB)을 폰에 저장해 두므로 그다음부터는 인터넷 없이(비행기 모드에서도) 됩니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
      • 학습 데이터: 메트로폴리탄·시카고·클리블랜드 미술관의 퍼블릭 도메인(CC0) 그림.
